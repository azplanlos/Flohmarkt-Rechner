# Flohmarkt-Rechner

Built with [Vite](https://vite.dev), React, [Tailwind CSS](https://tailwindcss.com) and [Konsta UI](https://konstaui.com).

## Available Scripts

### `npm start`

Runs the app in development mode at [http://localhost:5173/Flohmarkt-Rechner/](http://localhost:5173/Flohmarkt-Rechner/).

### `npm test`

Runs the tests with [Vitest](https://vitest.dev) in watch mode.

### `npm run build`

Type-checks the code and builds the app for production into the `build` folder.

### `npm run preview`

Serves the production build locally.

### `npm run deploy`

Builds the app and publishes the `build` folder to GitHub Pages.
